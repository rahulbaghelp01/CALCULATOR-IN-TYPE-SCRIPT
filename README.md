 
# Calculator in TypeScript

A simple calculator built with **HTML, CSS, and TypeScript** as a TypeScript learning project.

## What I Built

* Basic calculator operations: `+`, `−`, `×`, `÷`, `%`
* Clear, delete, decimal, and sign toggle
* Button hover animations
* Custom Google Font
* TypeScript DOM interactions

## What I Learned

* Type assertions
* DOM element selection
* `HTMLInputElement` and `HTMLButtonElement`
* Event listeners
* Type inference
* TypeScript compilation with `tsc`
* `tsconfig.json`
* String methods like `slice()` and `replaceAll()`
* Basic CSS Flexbox, Grid, transitions, and transforms

**Built to practice TypeScript by building a small project.**
